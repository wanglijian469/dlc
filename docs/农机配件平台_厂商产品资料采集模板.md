# 农机配件平台：厂商与产品资料采集模板

## 一、填写说明

- 一行填写一个厂商；一行填写一个产品。
- 同一个产品由多个厂商供应时，在“产品—厂商关系”表中分别填写。
- 优先提供企业官网、官方公众号、行业平台、企业店铺等公开来源。
- 所有网络资料请填写来源 URL 和访问日期。
- 不确定的信息请填写“待核实”，不要凭空补充。
- 图片可提供文件名或可访问 URL，原图另行打包提交。
