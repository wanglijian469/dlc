# 前台工业风改版验收

实施：2026-09-10；收尾核对：2026-09-11。

## 已实现

- 电脑前台采用石墨黑分类导航、暖白页面和工业橙操作按钮；顶部 72px，侧栏展开 248px、收起 72px。
- 首页搜索与行业图片分栏；推荐厂商、紧凑厂商目录和加工服务采用不同展示层次。
- 常驻分类支持整行展开、当前分类定位、图标提示、收起记忆及键盘操作；收起后选择父分类会打开对应分类。
- 列表、详情、搜索页统一公共框架；901–1199px 缩减侧栏和留白，首页首屏纵向排列。900px 及以下继续使用现有手机业务结构。
- 新设计集中在 `frontend/src/styles/public-industrial.css`，移除旧侧栏和首屏的 142 条选择器及卡片操作区强制覆盖。
- 首页错误状态沿用公共框架，骨架适配新版尺寸；保留接口、路由、模块配置和去重逻辑。

## 验证

- 全量 Vitest：46 个测试文件、134 项测试通过。
- 生产构建：TypeScript 与 Vite 构建通过；入口 JavaScript gzip 约 89 KiB，低于 120 KiB 上限。
- 浏览器矩阵：1440、1280、1024、900、390px，各检查首页、厂商列表、配件列表、厂商展厅、搜索页，共 25 组。等待结果组件可见后检查，无页面横向溢出或内容越界，最终浏览器控制台无错误。
- 实际操作：搜索输入回车跳转产品结果、清空历史、侧栏收起后刷新保持状态、键盘 Enter 展开分类、收起状态图标可见。
- 人工查看桌面首页、窄屏首页、厂商目录、配件列表、展厅和手机页面截图，修复搜索按钮换行、标题排列及旧卡片样式覆盖。
- 修复旧 `body` 横向 overflow 规则导致的吸附失效；实际滚动确认顶部导航与侧栏保持在预期位置。

## 预览与边界

浏览器验收使用 `.tmp/industrial-preview.mjs` 提供的独立模拟 API 和生产构建，监听 `127.0.0.1:5174`。示例厂商和产品仅用于排版验收，没有写入业务数据库，也没有部署上线。截图不代表真实已入驻厂商。

截图与尺寸检查结果保存在 `outputs/industrial-redesign/`：`home-desktop.png`、`home-lower.png`、`navigation-expanded.png`、`navigation-collapsed.png` 及各宽度页面截图；`viewport-checks.json` 记录矩阵结果。浏览器整页截图工具出现重复拼接，因此交付实际视口的首屏与下半页截图，未保留有拼接问题的长图。

本次未修改后台业务与数据库，仓库已有的其他未提交修改予以保留。真实生产数据、账户和网络环境的联调不包含在模拟浏览器验收结论内。
