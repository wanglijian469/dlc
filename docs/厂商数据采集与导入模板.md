# 厂商数据采集与导入模板

适用对象：入驻厂商、平台运营人员、具备管理员权限的数据采集人员。

填报原则：一家公司对应一份“厂商基础信息”；一个公开产品目录条目可关联多个厂商；同一厂商对同一产品只填写一条供应信息。带“必填”标记的字段是首次导入所需的最低数据集。

## 一、提交包目录

建议将一个厂商的资料整理为以下目录后压缩提交。图片应保留原始文件名，表格中的图片列填写相对路径。

```text
厂商简称_YYYYMMDD/
  01_厂商基础信息.xlsx（或按本模板填写）
  02_产品与供应信息.xlsx（或按本模板填写）
  images/
    logo.png
    factory-01.jpg
    product-001.jpg
    product-001-detail-01.jpg
  03_公开来源与授权说明.pdf（可选）
```

图片格式支持 JPG、PNG、WebP；单张建议不超过 5 MB，最短边不少于 800 px。平台上传时会统一转为 PNG 并按“年份/月/厂商编号”归档。

## 二、厂商基础信息表

每个厂商一行。厂商自提交或管理员录入时，均以可核验的厂商资料为准。

| 字段名 | 必填 | 示例/格式 | 填写说明 |
|---|---|---|---|
| 厂商名称 | 是 | 山东沃德农机配件有限公司 | 营业执照或公开官网名称；不得使用含糊简称 |
| 厂商简称 | 否 | 山东沃德 | 用于卡片展示，建议 2–10 个汉字 |
| 统一社会信用代码 | 建议 | 9137XXXXXXXXXXXXXX | 仅供后台去重与审核，不默认公开 |
| 厂商类型 | 是 | 生产厂商 / 经销商 / 加工服务商 | 可多选时用“、”分隔 |
| 省份 | 是 | 山东 | 使用省级行政区全称 |
| 城市 | 是 | 潍坊 | 使用地级市名称 |
| 区县 | 否 | 奎文区 | 可选 |
| 详细地址 | 建议 | 潍坊市…… | 公开前需确认可披露 |
| 联系人姓名 | 建议 | 张工 | 仅授权用户可见时填写 |
| 联系电话 | 建议 | 13800138000 | 前台匿名用户自动脱敏；必须确认已获授权 |
| 微信/邮箱 | 否 | sales@example.com | 仅提交业务联系方式 |
| 官网地址 | 否 | https://www.example.cn | 必须为完整 URL |
| 成立年份 | 否 | 2012 | 四位年份 |
| 员工规模 | 否 | 50–99 人 | 可填范围或准确人数 |
| 厂房面积 | 否 | 12000㎡ | 数值加单位 |
| 年产能 | 否 | 年产齿轮 30 万件 | 说明产品与量纲 |
| 主营产品 | 是 | 齿轮、链轮、轴承座 | 用“、”分隔，尽量使用配件名称 |
| 服务机型 | 否 | 收割机、拖拉机 | 用“、”分隔 |
| 厂商简介 | 建议 | 100–500 字 | 说明主营能力、市场和优势，不写夸大宣传 |
| 服务优势 | 否 | 支持来图定制、小批量打样 | 用短句分隔 |
| 主要设备 | 否 | 数控车床、滚齿机、检测台 | 用“、”分隔 |
| 认证资质 | 否 | ISO9001、专利证书 | 仅填写可核验内容 |
| 售后服务 | 否 | 12 个月质保 | 明确条件与期限 |
| 是否提供加工服务 | 是 | 是 / 否 | 选择“是”后必须填写下一节 |
| 推荐排序 | 否 | 100 | 数字越小越靠前；管理员维护 |
| Logo 图片路径 | 否 | images/logo.png | 一张正方形或横向清晰图 |
| 厂房封面图片路径 | 否 | images/factory-01.jpg | 一张横向实拍图；没有可留空 |
| 厂商状态 | 管理员 | 草稿 / 已发布 / 已隐藏 | 厂商填报无需填写 |
| 资料审核状态 | 管理员 | 待审核 / 已核验 / 已驳回 | 审核过程字段 |

## 三、加工服务补充表

仅“是否提供加工服务=是”的厂商填写，每厂商一行。

| 字段名 | 必填 | 示例/格式 | 填写说明 |
|---|---|---|---|
| 厂商名称 | 是 | 山东沃德农机配件有限公司 | 与基础信息完全一致 |
| 加工服务类型 | 是 | 车削、铣削、滚齿、焊接 | 用“、”分隔 |
| 加工材料 | 否 | 钢件、铸铁、铝合金 | 用“、”分隔 |
| 加工设备 | 建议 | 加工中心、数控车床 | 用“、”分隔 |
| 加工能力/交期 | 建议 | 小批量 3 天，批量按图报价 | 量化说明 |
| 服务区域 | 否 | 华北、全国 | 用“、”分隔 |
| 接单说明 | 否 | 支持图纸、样件、来样加工 | 写明资料要求 |
| 加工服务图片路径 | 否 | images/service-01.jpg | 可多张，用“；”分隔 |

## 四、公共产品目录表

产品目录保存平台通用资料，不绑定单一供应商。若是厂商首次提交且平台没有该产品，可填写“建议新建”；若平台已有，填写“关联已有产品”并提供已有产品 ID 或规范名称。

| 字段名 | 必填 | 示例/格式 | 填写说明 |
|---|---|---|---|
| 产品处理方式 | 是 | 建议新建 / 关联已有产品 | 厂商只能建议，管理员最终决定 |
| 平台产品 ID | 关联时必填 | 16 | 平台已有产品填写；未知可留空 |
| 公共产品名称 | 是 | 变速箱齿轮总成 | 使用通用名称，不包含某一家厂商名称 |
| 产品分类 | 是 | 传动配件 > 齿轮 | 使用平台分类层级；管理员可映射 |
| 通用适配机型 | 建议 | 联合收割机、拖拉机 | 通用信息，不填厂商专有型号 |
| 公共产品说明 | 建议 | 适用于…… | 说明功能、结构、应用范围 |
| 规格参数 JSON/表格 | 否 | 模数=3；齿数=28；材质=20CrMnTi | 一行一个“参数名=参数值”，或另附参数表 |
| 标准主图路径 | 建议 | images/product-001.jpg | 不带商标水印的通用配图优先 |
| 标准详情图路径 | 否 | images/product-001-detail-01.jpg；images/product-001-detail-02.jpg | 多张用“；”分隔 |
| 推荐产品 | 管理员 | 是 / 否 | 后台运营字段 |
| 热门产品 | 管理员 | 是 / 否 | 后台运营字段 |
| 目录发布状态 | 管理员 | 草稿 / 已发布 / 已隐藏 | 至少有一个已通过供应商后才可前台展示 |

## 五、厂商供应信息表

这是产品导入的核心表。每一行代表“一个厂商供应一个公共产品”。不同厂商可填写同一个平台产品 ID，前台会合并为一张产品卡片并显示供应商数量。

| 字段名 | 必填 | 示例/格式 | 填写说明 |
|---|---|---|---|
| 厂商名称 | 是 | 山东沃德农机配件有限公司 | 与基础信息完全一致 |
| 平台产品 ID | 建议 | 16 | 关联已有目录时必填；新建候选可先留空 |
| 公共产品名称 | 是 | 变速箱齿轮总成 | 用于未提供 ID 时匹配 |
| 本厂产品名称 | 是 | WD-变速箱齿轮总成 | 可与公共名称相同 |
| 本厂型号 | 建议 | WD-GEAR-28-03 | 厂商内部型号、图号或订货号 |
| 本厂适配信息 | 建议 | 适配 4LZ-6.0 收割机 | 可比公共适配信息更具体 |
| 本厂供应说明 | 建议 | 锻造毛坯，渗碳淬火 | 说明材质、工艺、库存、最小起订量等 |
| 价格说明 | 建议 | 按型号报价，100 件起批 | 不建议填写易过期的固定价格 |
| 询价文案 | 否 | 联系山东沃德询价 | 前台联系按钮文字 |
| 询价跳转地址 | 否 | /vendors/1 | 通常由平台自动生成，无需厂商填写 |
| 本厂主图路径 | 否 | images/product-001-vendor.jpg | 可包含本厂包装/型号，审核后展示在供应商信息中 |
| 本厂详情图路径 | 否 | images/product-001-vendor-detail.jpg | 多张用“；”分隔 |
| 供应状态 | 管理员 | 待审核 / 已通过 / 已驳回 / 已停用 | 厂商提交默认待审核 |
| 审核意见 | 管理员 | 图片不清晰，请补充型号 | 审核过程字段 |

## 七、导入与审核规则

1. 管理员先导入厂商基础信息，再导入公共产品目录，最后导入厂商供应信息和图片。
2. 厂商名称、统一社会信用代码、官网域名应作为去重依据；名称相似但无法确认时不得自动合并。
3. 公共产品名称相同不代表自动合并。管理员应比对分类、适配机型和规格后，再将多个厂商关联到同一目录产品。
4. 厂商自提交的新产品、关联已有产品和修改供应信息均进入产品审核；审核期间已通过的旧供应信息继续前台展示。
5. 公共产品必须为“已发布”，且至少有一家“已通过”的可见厂商供应，才会出现在产品列表、搜索和详情页。
6. 电话、微信等联系方式须取得厂商授权。匿名访客默认只看脱敏号码，登录用户按权限查看完整信息。
7. 图片必须确认拥有使用权。公开网页图片仅在版权、授权和平台规则允许时导入；无法确认时不得上传复制件。

## 八、提交前自检清单

- 厂商名称、所在地、主营产品已填写。
- 联系方式和图片已确认可对外使用。
- 每个产品已区分“公共目录资料”和“本厂供应信息”。
- 产品图片路径存在，且文件可打开、无敏感信息、无无关水印。
- 平台已有产品已优先填写产品 ID，避免重复建档。
- 不确定、过期或未经授权的字段已留空并标记待厂商确认。
