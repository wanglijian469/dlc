# 河北冀农半自动导入设计

## 目标

将河北冀农官网公开展示的信息导入本网站，作为厂商目录中的真实厂商之一，同时保留人工复核入口，避免把公开采集内容误当作平台认证内容。

## 范围

- 新增河北冀农厂商档案，包含企业名称、官网、地区、地址、主营产品、企业简介、规模、设备、服务区域、联系人信息和公开信息来源。
- 新增若干代表产品，关联到河北冀农厂商。
- 厂商数据增加采集来源与复核状态字段，后台可编辑，前台详情页可提示“公开信息待复核”。
- 不批量下载官网图片，不搬运整站内容；官网图片和更详细产品参数留给人工复核后补充。

## 数据来源

来源为 https://www.hbjinong.com/ 首页公开文本，以及官网导航中公开展示的产品分类与联系方式。导入内容只摘取事实型信息：公司名称、官网、地址、电话、成立年份、占地面积、员工规模、设备规模、主营产品和区域联系人。

## 数据设计

在 `Vendor` 上补充：

- `SourceURL`：公开信息来源链接。
- `SourceNote`：采集说明，记录采集日期和待复核项。
- `ReviewStatus`：复核状态，默认 `pending`，可选 `pending`、`verified`、`rejected`。

平台认证仍使用现有 `IsVerified` 字段。河北冀农初始导入时 `ReviewStatus=pending` 且 `IsVerified=false`，人工确认后可在后台改为 `verified` 并按需设置平台认证。

## 导入方式

先把河北冀农纳入默认 seed，作为 MVP 启动后即可见的数据。后续如果继续导入更多厂商，再抽出独立采集脚本；当前只为一个厂商做脚本会增加维护面。

## 展示策略

厂商列表继续使用现有卡片。厂商详情页在标签区显示复核状态提示，并在档案区域展示来源链接和采集说明，便于后台运营人员核对。

## 验证

- 后端 seed 测试覆盖河北冀农厂商、来源字段和代表产品。
- 后端 API 序列化测试覆盖新增来源与复核字段。
- 前端详情页测试覆盖待复核提示和来源信息展示。
