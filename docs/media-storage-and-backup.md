# 图片资源存储与备份

平台上传的图片统一保存在后端 `MEDIA_DIR` 指定的目录中，数据库只保存资源记录和相对存储键。默认目录为 `media_storage`，生产环境应将 `MEDIA_DIR` 指向独立的数据盘，例如 `D:\dalu-data\media`。

目录按“年份 / 月份 / 归属厂商”组织：

```text
media/
  2026/
    07/
      vendor-18/
        <随机文件名>.png
      shared/
        <随机文件名>.png
```

- `vendor-{id}`：厂商账号上传的 Logo、厂房、设备、证书和产品图片。
- `shared`：平台管理员上传的公共图片。
- 文件名使用随机值，原始文件名、哈希、尺寸、归属和发布状态记录在 `media_assets` 表中。
- 上传图片会重新编码为 PNG，去除 EXIF 等附加元数据。

## 备份范围

一次可恢复备份必须同时包含：

1. MySQL 数据库全量备份；
2. 整个 `MEDIA_DIR` 目录；
3. 生产环境配置中与数据库、`MEDIA_DIR` 相关的非敏感配置清单。

建议每日增量备份、每周全量备份，并至少保留一份异地副本。恢复时先恢复数据库，再将媒体目录恢复到相同的 `MEDIA_DIR` 路径；不要单独重命名或移动目录内文件。
