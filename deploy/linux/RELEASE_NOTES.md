# 2026.07.30 Linux 发布说明

本版本修复以下问题：

- 移除“发布说明”后，管理员可直接发布自己提交的厂商、产品及其他内容修订；
- 配件产品仍必须关联至少一家已发布且前台可见的厂商；
- 网站图标压缩为 64×64、约 7.5 KB，减少首屏额外流量；
- Linux 升级健康检查最多等待 30 秒，避免服务启动过程中被误判失败并回滚；
- 修正升级失败时显示的数据库与媒体备份路径。

本部署包同时包含公开信息防采集能力：

- 厂商可分别控制电话、微信和联系人公开展示或登录后可见；
- 公开图片使用水印展示图，保留受保护的原图；
- AI 爬虫规则、慢速采集识别、风险记录、封禁和白名单；
- Nginx 对页面、列表、搜索接口和媒体请求进行限流；
- 数据更新后将旧静态页面标记为需要重新生成，避免继续展示旧信息。

升级步骤请阅读 `docs/UPGRADE.md`。首次启用访问防护后的 7 天内，建议保持
“仅记录，不自动封禁”。
