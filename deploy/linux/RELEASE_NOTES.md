# 2026.09.11 Linux 发布说明（v2026.09.11-linux.1 / Schema 23）

本版统一电脑前台为现代工业品牌风，重做常驻分类导航、首页层次及厂商卡片。厂商卡片改为单封面，Logo 与名称并排显示，并完善缺图和图片加载失败时的占位表现。

供求信息功能已从电脑前台、移动网页、管理后台、Flutter 客户端和共享接口契约中移除。Schema 23 会删除 `market_post_media`、`market_contact_access_logs`、`market_posts` 三张专用表，并清理旧菜单、占位内容页和静态页面缓存。升级脚本会先备份数据库和媒体文件；数据库删除完成后如需回滚，必须同时恢复升级前的数据库备份和旧程序。

升级后应确认首页、厂商与配件目录可访问，`/purchase` 及供求 API 返回 404，并重新生成标记为待更新的静态页面。

## v2026.08.23-linux.2 累计功能

本次增量升级新增产品与厂商图片体验和厂商产品供货字段优化：

- 产品主图、产品图集、产品参数图和企业图集支持全屏灯箱预览；
- 多图支持循环切换、计数、说明、键盘方向键、Esc 和手机左右滑动；
- 图片继续使用公开水印地址，不开放原始私有图片和下载入口；
- PC 产品图片和企业图集按原图比例完整显示，不再裁切；
- 厂商新增、编辑及即时更新产品时，计价单位、起订量、可供应量、交期、
  运费说明和供货能力使用统一预设选项；
- 新产品带入常用默认值，历史自定义值继续保留；
- 即时更新接口和价格历史记录增加供货能力快照。

数据库架构版本仍为 19，本次不新增表或字段。`initdb` 迁移可重复执行；升级脚本
仍会在替换程序前备份数据库、上传媒体和旧程序，并在升级后执行健康检查。

## v2026.08.23-linux.1 累计功能

本版本新增厂商纸质材料智能采集与审核录入能力：

- 管理员和厂商可按资料包连续拍摄名片、产品彩页并进行人工校对；
- 新增数据库持久化识别队列，服务重启后可恢复未完成任务；
- 新增低置信字段确认、重复厂商/产品匹配、产品候选裁图和审核提交；
- 原始材料和候选裁图按私有媒体保存，不会通过公开媒体接口访问；
- 新增七天有效、单次使用的厂商接管邀请链接；
- 腾讯云高精度 OCR 和名片识别继续使用 SecretId/SecretKey；
- 混元视觉已迁移到 TokenHub OpenAI 兼容接口，使用独立 TokenHub API Key；
- 管理后台“平台配置 → 智能采集云服务”支持加密保存密钥且不会回显明文。

数据库架构升级到版本 19，新增：

- `capture_packages`
- `capture_documents`
- `capture_results`
- `capture_product_crops`
- `vendor_invitations`

同时扩展媒体用途和厂商、产品审核记录的资料包来源字段。升级脚本执行前会自动备份
数据库、上传媒体和旧程序。请勿跳过 `sha256sum -c SHA256SUMS` 和健康检查。

完整升级：

```bash
sudo ./scripts/upgrade.sh
```

仅执行数据库升级：

```bash
sudo ./scripts/database-upgrade.sh
```

详细步骤和回滚方式请阅读 `docs/UPGRADE.md`。
