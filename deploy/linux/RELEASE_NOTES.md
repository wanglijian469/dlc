# 2026.08.12 Linux 发布说明

本版本完成厂商资料、产品录入和公开展示链路升级：

- 厂商网址使用 3–16 位小写字母数字短标识，旧地址保留重定向；
- 删除厂商级“适配机型”和“售后服务”字段，产品级适配信息保持不变；
- 厂商只维护本厂产品，平台运营在审核时决定关联已有标准产品或创建新产品；
- 厂商详情页重排服务优势、联系方式、微信二维码和企业实力信息；
- 图片水印改为右下角中文轻水印，并内置中文字体；
- 修复私密微信二维码预览和发布后的显示链路；
- 厂商分类导航不再显示数量和“招商中”徽标；
- 网站 favicon、后台侧栏及登录页统一使用新版麦穗齿轮 Logo；
- 清理指定模拟厂商数据和历史演示内容。

数据库迁移会删除已停用的厂商字段及其历史审核快照值。升级脚本会在迁移前自动备份
数据库、上传媒体和旧程序；请勿跳过 `sha256sum -c SHA256SUMS` 和健康检查。

升级只需解压部署包并执行：

```bash
sudo ./scripts/upgrade.sh
```

详细步骤和回滚方式请阅读 `docs/UPGRADE.md`。
